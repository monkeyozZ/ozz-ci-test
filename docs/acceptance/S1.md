# S1 基础工程交付与验收

日期：2026-10-25（Asia/Shanghai）。对应 S1.01–S1.10，涉及 F01–F04、F09/F22/F23/F24/F25 的基础部分。**本地工程、58 项集成测试、生产浏览器及 14 项 Compose 部署检查已通过；本记录交付 S1 的实现和本地自动化证据，完整 MVP 与真实云部署仍按后续阶段验收。**

## 已实现范围

- pnpm workspace：独立 API、Worker、Console，以及 database/config/control-plane/api-client 包。项目 Node 24.22.1 与全局 Node 分开。
- 单管理员 CLI 初始化、Argon2id 密码、HttpOnly 会话、CSRF/Origin、持久限速。每个 API 进程仅同时执行一次密码验证，繁忙时返回 `503 AUTH_BUSY`，启动时先完成未知账号使用的校验哈希；无公开注册或默认密码。
- 真实 PostgreSQL 迁移及项目/环境/集群/服务器 CRUD。项目目标固定、默认 production 同事务创建，数据库触发器阻止普通改挂归属，删除检查引用与 revision。
- AES-256-GCM 版本化凭证与主密钥校验。普通 API 仅返回元数据，日志脱敏；错/缺密钥拒绝启动。
- Operation/Outbox + BullMQ，事务幂等、Worker 租约、取消/重试、generation fence、恢复锁、心跳与有界诊断日志。Redis 故障时先持久接收，恢复后补投递。
- 基于已批准 Stitch 视觉与交互的真实 Vue 控制台：项目上下文、元数据表单、凭证、诊断、明暗主题、窄屏导航和命令面板；未实现功能不提供虚假操作入口。
- OpenAPI 生成契约类型、开发/生产 Compose、镜像构建和控制面备份/恢复脚本，以及 CI 定义。

## 使用与下一阶段
